# Heightmap Studio

Terrain and track editor for motocross and supercross games.

**Download** the newest version from [Releases](https://github.com/bradenmackey/hms-public/releases/latest) or [heightmapstudio.com](https://heightmapstudio.com).

- Windows: `Heightmap-Studio-setup.exe`
- Linux: `Heightmap-Studio.AppImage`, or the `.deb` / `.rpm`

Once installed, the app updates itself. This repository holds releases only.
